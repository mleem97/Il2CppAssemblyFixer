## Overview

**Il2CppAssemblyFixer** is part of the gregFramework tooling around **gregCore**. It repairs DLLs generated by MelonLoader's IL2CPP assembly generation pipeline when Unity updates introduce duplicate type metadata or broken assembly output.

It ships as both:

- a standalone Windows/Linux fixer for manual repair after game updates, and
- a MelonLoader plugin that runs automatically before mods are loaded.

## Compatibility

| Game | Developer | Loader | Status |
|------|-----------|--------|--------|
| Data Center | Waseku | MelonLoader 0.7.2+ | Verified |
| Other Unity 6 IL2CPP titles | Various | MelonLoader 0.7.2+ | Untested; issue reports welcome |

## The Problem

Certain Unity 6 updates can cause MelonLoader's assembly generator to produce malformed DLLs with duplicate type definitions. A typical crash looks like this:

```text
System.BadImageFormatException: Duplicate type with name '<>O' in assembly 'UnityEngine.CoreModule'
```

Known cases include:

| Issue | Symptom | Root cause |
|-------|---------|------------|
| CoreModule crash | `BadImageFormatException` | Duplicate compiler-generated delegate cache types |
| Collections crash | `ModuleWriterException` in `Unity.Collections.dll` | Nested types referenced via generic `TypeSpec` wrappers not counted |
| Scene crash | `SceneHandler.Init()` crash | Unity 6 scene API changes |
| Stripping | `Method Unstripping Failed` | Unity methods stripped or moved |

## Features

- dnlib-based duplicate type detection and safe removal
- Mono.Cecil metadata normalization after structural changes
- Manifest-based plugin cache using `.il2cppfixer-manifest`
- Automatic MelonLoader plugin mode via `OnPreInitialization`
- Standalone Windows and Linux binaries
- `.bak` backups before modified assemblies are written
- `--restore` support for reverting backups
- `fixer_config.json` for logging and telemetry settings

## Installation

### Standalone Windows

1. Launch the game once so MelonLoader generates `<GameFolder>/MelonLoader/Il2CppAssemblies/`.
2. Extract the `win-x64` ZIP.
3. Run:

```powershell
.\Il2CppAssemblyFixer.exe
```

Useful options:

```powershell
.\Il2CppAssemblyFixer.exe "D:\Games\Data Center\MelonLoader\Il2CppAssemblies"
.\Il2CppAssemblyFixer.exe --rewrite
.\Il2CppAssemblyFixer.exe --restore
```

### Standalone Linux / Proton

```bash
unzip Il2CppAssemblyFixer_*_linux-x64.zip
chmod +x Il2CppAssemblyFixer
./Il2CppAssemblyFixer "/path/to/Data Center/MelonLoader/Il2CppAssemblies"
```

### MelonLoader plugin

1. Open the MelonLoader plugin ZIP.
2. Copy these DLLs into `<GameFolder>/Plugins/`:
   - `Il2CppAssemblyFixerPlugin.dll`
   - `dnlib.dll`
   - `Mono.Cecil.dll`
3. Copy `fixer_config.json` into `<GameFolder>/MelonLoader/`.
4. Launch the game.

## Custom / non-Steam installs

If auto-detection fails, create `game-path.txt` next to the standalone executable and place either the game root or the `Il2CppAssemblies` directory inside:

```text
D:\Games\Data Center\MelonLoader\Il2CppAssemblies
```

Auto-detection checks:

1. `game-path.txt`
2. Steam registry and `libraryfolders.vdf`
3. Linux/macOS Steam roots
4. Common Steam library folders on all drives
5. Common custom game folders on all drives
6. User-profile folders such as Desktop, Downloads, and Documents

## Configuration

The fixer reads `<GameFolder>/MelonLoader/fixer_config.json`.

```jsonc
{
  "logging": {
    "writeLogFile": true,
    "logFileName": "fixer.log",
    "minimumLevel": "Debug"
  },
  "telemetry": {
    "enabled": true,
    "endpoint": "https://loki.example.com/loki/api/v1/push",
    "format": "loki",
    "username": "",
    "apiKey": "",
    "tenantId": "",
    "anonymousId": "",
    "includeAssemblyList": true,
    "includeMachineInfo": true,
    "timeoutSeconds": 5
  }
}
```

`apiKey` is preserved as the JSON field name for backwards compatibility. Internally it is treated as an auth token.

## Telemetry

Telemetry is configurable in `fixer_config.json`. It reports non-identifying run counters such as assembly counts, errors, duration, variant, version, and a random installation ID. It does not send file paths, usernames, hostnames, assembly contents, saves, or game data.

To opt out:

```json
"telemetry": { "enabled": false }
```

See [`README_TELEMETRY.md`](README_TELEMETRY.md) for the full notice.

## Safety and backups

- Protected runtime assemblies such as `Il2CppInterop.Runtime.dll`, `mscorlib.dll`, and `netstandard.dll` are never modified.
- Unity core modules are processed conservatively.
- Every modified DLL is backed up as `<file>.bak` before changes are written.
- Run `Il2CppAssemblyFixer.exe --restore` to restore all `.dll.bak` files.

## Build from source

Requirements:

- .NET 10 SDK for the standalone app
- .NET 6 SDK for the MelonLoader plugin

```bash
git clone https://github.com/mleem97/Il2CppAssemblyFixer.git
cd Il2CppAssemblyFixer
dotnet restore Il2CppAssemblyFixer.sln
dotnet build -c Release
```
